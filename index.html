先看懂：sin x + cos x 怎麼疊成一條波？

課本的第一個重點先把 sin x 和 cos x 相加，再用「正弦的和角公式」把它改寫成一個正弦函數。
y=sin x + cos x
=√2（1√2 sin x + 1√2 cos x）
=√2（sin x cos π4 + cos x sin π4）
=√2 sin（x + π4）
白話解讀：
原本兩條波相加後，還是一條正弦波。
振幅變成 √2，整條波向左平移 π/4，週期仍是 2π。
馬上確認： sin x + cos x 的最大值是多少？

用疊合直接求最大值、最小值

這裡最簡單 如果 y = a sin x + b cos x：
最大值 = R，最小值 = −R。

如果還有上下平移 D：
最大值 = D + R，最小值 = D − R。

這一招只要 x 沒有限制範圍，就可以直接用。
綠色虛線是最大值，紅色虛線是最小值。圖形左右平移不會改變振幅。
4

x 有範圍時：先看「最高點、最低點有沒有被截掉」

課本固定例題 y = sin x − √3 cos x + 5
先疊合成：
y=sin x − √3 cos x + 5
=2 sin（x − π3）+ 5
完整一週能取到最高 7、最低 3；如果範圍縮短，就要檢查最低點還在不在。
5

用疊合解方程式

課本例題 在 0 ≤ x < 2π 內，解：
sin x − √3 cos x = 1
sin x − √3 cos x = 1
→2 sin（x − π3）= 1
→sin（x − π3）= 12
→x − π3 = π6　或　5π6
→x = π2　或　7π6
白話流程：先把左邊疊成一個 sin → 再像普通三角方程式一樣解。
紫色點就是兩個解：x = π/2、7π/6。

課本最後應用：圓窗內接矩形

矩形兩邊：100 sin x、100 cos x。
